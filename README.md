# Job Alert Agent

בוט טלגרם שמתריע על משרות חדשות בחברות שאתה בוחר לעקוב אחריהן.

## הקמה

1. **צור ריפו ב-GitHub** והעלה אליו את כל הקבצים האלה.

2. **הוסף Secrets** (Settings → Secrets and variables → Actions):
   - `BOT_TOKEN` — הטוקן מ-@BotFather
   - `CHAT_ID` — ה-chat_id שלך (316221230)
   - `ANTHROPIC_API_KEY` — אופציונלי. מפתח API מ-console.anthropic.com. בלעדיו, `/add` עדיין יזהה אוטומטית
     Lever / Comeet / Greenhouse / Ashby / Recruitee / SmartRecruiters / Workday, כולל כשנותנים את עמוד
     הקריירות העצמאי של החברה (הוא יחפש בתוכו קישור לאחת הפלטפורמות האלה). המפתח נדרש רק בשביל
     המקרה הנדיר של אתר קריירות בפלטפורמה לא מוכרת - אז נעזרים ב-LLM כדי לזהות selector אוטומטית.

3. **וודא ששני ה-workflows דלוקים**: Actions tab → אם צריך, אשר "I understand my workflows, go ahead and enable them".

## שימוש

שלח הודעות לבוט שלך בטלגרם:

- `/add <שם חברה> <URL>` — מוסיף חברה למעקב. פשוט תן שם וכתובת (אפשר גם את עמוד הקריירות הרגיל של
  החברה, לא חייב קישור ישיר לפלטפורמת הגיוס) — הבוט מזהה לבד באיזו פלטפורמה משתמשים ואיך לשלוף ממנה
  משרות. אין יותר שלב של selector ידני.
- `/list` — מציג את כל החברות שבמעקב
- `/remove <שם חברה>` — מסיר חברה מהמעקב

## תזמון

- `commands.yml` רץ כל 10 דקות — מטפל בפקודות שלך
- `check.yml` רץ כל 3 שעות — בודק משרות חדשות ושולח התראה

בפעם הראשונה שחברה נוספת, לא תישלח התראה (כי אין "קודם" להשוואה) — רק החל מהריצה השנייה.
